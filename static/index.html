MONTHLY BUDGET

设置月度预算

开始使用有数

  1. 记下收入和支出

    点击「记一笔」，填写金额、日期、类别和备注。金额填写正数，由收支类型决定用途。

  2. 查看与筛选

    用日期、类别、金额或备注筛选账目。上方汇总和右侧图表只统计筛选后的记录。

  3. 设置月度预算

    在「月度预算」卡片选择月份并设置金额，通过进度条查看已用和剩余额度。预算统计该月全部支出，不受筛选影响；超支时会以红色文字提示。

  4. 导出筛选结果

    点击「导出 CSV」，当前筛选匹配的全部记录（包含未显示的分页）会保存为 Excel 可打开的表格文件。导出只是下载文件，不会改变当前筛选和账目列表。

  5. 保管好本地账本

    默认数据保存在项目的 data/ledger.json 文件中。关闭程序后仍然保留；可在页面下方下载 JSON 备份；恢复前请核对记录数和日期范围，恢复将替换全部账目。请妥善保管备份。

确认恢复账本

恢复会替换当前全部账目，不会与现有记录合并。请确认已妥善保存当前备份。
