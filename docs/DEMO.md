# 现场演示流程（约 3 分钟）

建议用独立账本演示：`python app.py --data .qa/demo.json --port 8001 --open`。正式账本保存在 `data/ledger.json`，不要用真实隐私记录录屏。

## 演示顺序

1. 介绍浏览器界面与本地文件存储，展示空账本。
2. 新增三笔同一天的示例记录：工资收入 5,000 元、餐饮支出 25.50 元、交通支出 6 元。其中工资用「一句话记账」录入：输入「收到工资 5000」并回车，展示对话框顶部的识别结果和预填内容，确认后保存；再输入「买了本书」展示“没有识别到金额”的提示。
3. 确认汇总：收入 5,000.00，支出 31.50，结余 4,968.50，记录数 3；展示支出分类图。
4. 筛选餐饮类别，确认支出为 25.50；此时点击账目明细右上角「导出 CSV」，打开下载的 `account-book.csv`，确认只有表头和这一条记录（行数与筛选结果一致，而不是当前页的条数），并且筛选条件和列表没有被改变；重置，再用最低金额 20 和最高金额 30 筛选。
5. 编辑餐饮金额为 28.50，重置筛选后确认支出 34.50、结余 4,965.50。
6. 点击删除交通记录，先取消，确认数据未变；再次删除并确认。
7. 刷新浏览器，关闭并重新启动程序，确认记录仍存在。
8. 展示 JSON 中的 `amount_cents`，解释整数分与原子写入。

## 截图和录屏建议

- 收支概览：有收入、两类支出，汇总和分类图完整可见。
- 记账弹窗：日期、金额、类别和备注字段。
- 筛选结果：有明确条件与对应汇总。
- 移动端窄屏布局可作为附加截图。

录屏请使用实际运行画面，按顺序操作，核对没有真实个人收支或账户信息。将最终视频链接和截图加入博客；此文档本身不是演示已完成的证明。
